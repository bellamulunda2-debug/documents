Use this endpoint to record when a user interacts with another user's content on Xera. Every call you make creates an entry in the interaction log and, as a side effect, triggers automatic recalculation of the target creator's retention metrics and the viewer's affinity score toward that creator — keeping the recommendation engine current without any extra work on your side.

## Endpoint

```
POST https://xera.app/api/app/interaction/track
```

## Authentication

<Note>
  This endpoint requires a valid session token. Include it in every request as a Bearer token in the `Authorization` header.
</Note>

```
Authorization: Bearer <session_token>
```

## Request Body

<ParamField body="interaction_type" type="string" required>
  The type of interaction being recorded. Must be one of: `view`, `like`, `share`, `comment`, `bookmark`, or `follow`.
</ParamField>

<ParamField body="target_user_id" type="string (UUID)" required>
  The UUID of the user whose content was interacted with.
</ParamField>

<ParamField body="content_id" type="string (UUID)">
  The UUID of the specific content item the user interacted with. Omit if the interaction targets a profile directly (e.g., a follow).
</ParamField>

<ParamField body="content_type" type="string">
  The type of the content item. Must be one of: `video`, `stream`, or `profile`. Required when `content_id` is provided.
</ParamField>

<ParamField body="engagement_duration" type="number">
  The number of seconds the user spent engaging with the content. Used to refine retention and affinity scoring.
</ParamField>

<ParamField body="metadata" type="object">
  An optional object for any additional contextual data you want to attach to the interaction record (e.g., playback position, referral source).
</ParamField>

## Success Response

**Status: `201 Created`**

<ResponseField name="success" type="boolean">
  `true` when the interaction was recorded successfully.
</ResponseField>

<ResponseField name="data" type="object">
  The newly created interaction record.

  <Expandable title="data fields">
    <ResponseField name="id" type="string (UUID)">
      The unique identifier of the interaction record.
    </ResponseField>

    <ResponseField name="interaction_type" type="string">
      The type of interaction that was recorded.
    </ResponseField>

    <ResponseField name="created_at" type="string (ISO 8601)">
      The timestamp at which the interaction was saved.
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Responses

| Status | Error message | Cause |
|--------|--------------|-------|
| `400`  | `"interaction_type et target_user_id sont requis"` | `interaction_type` or `target_user_id` was omitted from the request body. |
| `401`  | `"Non authentifié"` | The `Authorization` header is missing, expired, or invalid. |

## Side Effects

<Info>
  Every successful call to this endpoint automatically triggers two background updates:

  1. **Retention metrics** — the target creator's retention data is recalculated to reflect the latest return-visitor rate and total session count.
  2. **Affinity score** — the affinity score between the viewing user and the target creator is updated, which influences how often that creator appears in the viewer's discovery feed.

  You do not need to call any additional endpoint to trigger these updates.
</Info>
