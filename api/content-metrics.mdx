title: "POST /api/app/content-metrics/update — Update Metrics"

Use this endpoint to report how users engage with specific content on Xera. Completion rate and watch or read duration are two of the strongest quality signals available to the recommendation engine — the more accurately you report them, the better Xera can surface the right content to the right audience. Call this endpoint when a user finishes a video, closes a trace mid-read, or pauses a live stream replay.

## Endpoint

```
POST https://xera.app/api/app/content-metrics/update
```

## Authentication

<Note>
  This endpoint requires a valid session token passed as a Bearer token in the `Authorization` header.
</Note>

```
Authorization: Bearer <session_token>
```

## Request Body

<ParamField body="content_id" type="string (UUID)" required>
  The UUID of the content item whose metrics you are updating.
</ParamField>

<ParamField body="content_type" type="string" required>
  The type of content being reported (e.g., `video`, `stream`, `trace`).
</ParamField>

<ParamField body="completion_rate" type="number">
  A decimal between `0.0` and `1.0` representing how much of the content the user consumed. `0.0` means nothing was watched or read; `1.0` means the user reached the end.
</ParamField>

<ParamField body="engagement_duration" type="number">
  The total number of seconds the user spent on this content item during the current session.
</ParamField>

## Example Request

<CodeGroup>

```javascript JavaScript
const response = await fetch(
  "https://xera.app/api/app/content-metrics/update",
  {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "Authorization": "Bearer <session_token>",
    },
    body: JSON.stringify({
      content_id: "f0e9d8c7-b6a5-4321-fedc-ba9876543210",
      content_type: "video",
      completion_rate: 1.0,
      engagement_duration: 142,
    }),
  }
);

const result = await response.json();
console.log(result);
```

```bash cURL
curl -X POST https://xera.app/api/app/content-metrics/update \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <session_token>" \
  -d '{
    "content_id": "f0e9d8c7-b6a5-4321-fedc-ba9876543210",
    "content_type": "video",
    "completion_rate": 1.0,
    "engagement_duration": 142
  }'
```

</CodeGroup>

## Success Response

**Status: `200 OK`**

<ResponseField name="success" type="boolean">
  `true` when the metrics were saved or updated successfully.
</ResponseField>

<ResponseField name="data" type="object">
  The updated content metrics record for the current user and content item.

  <Expandable title="data fields">
    <ResponseField name="id" type="string (UUID)">
      The unique identifier of the metrics record.
    </ResponseField>

    <ResponseField name="content_id" type="string (UUID)">
      The UUID of the content item this record belongs to.
    </ResponseField>

    <ResponseField name="content_type" type="string">
      The type of content (e.g., `video`, `stream`, `trace`).
    </ResponseField>

    <ResponseField name="completion_rate" type="number">
      The latest completion rate stored for this user and content item.
    </ResponseField>

    <ResponseField name="avg_watch_time" type="number">
      The latest engagement duration (in seconds) stored for this session.
    </ResponseField>

    <ResponseField name="engagement_score" type="number">
      A computed score derived from `completion_rate` and `engagement_duration`. Used internally by the recommendation engine.
    </ResponseField>

    <ResponseField name="view_count" type="number">
      The total number of times this endpoint has been called for this content item by the current user on the current day.
    </ResponseField>
  </Expandable>
</ResponseField>

## Common Use Cases

<Tabs>
  <Tab title="Video completed">
    When a user watches a video all the way through, send `completion_rate: 1.0` along with the actual runtime in seconds.

    ```javascript
    await fetch("https://xera.app/api/app/content-metrics/update", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Authorization": "Bearer <session_token>",
      },
      body: JSON.stringify({
        content_id: "VIDEO_UUID",
        content_type: "video",
        completion_rate: 1.0,
        engagement_duration: 180, // 3-minute video
      }),
    });
    ```
  </Tab>
  <Tab title="Trace closed mid-read">
    When a user closes a Trace after reading for 45 seconds, omit `completion_rate` and send `engagement_duration` only.

    ```javascript
    await fetch("https://xera.app/api/app/content-metrics/update", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Authorization": "Bearer <session_token>",
      },
      body: JSON.stringify({
        content_id: "TRACE_UUID",
        content_type: "trace",
        engagement_duration: 45,
      }),
    });
    ```
  </Tab>
  <Tab title="Partial video view">
    When a user drops off halfway through a video, send the fraction watched as `completion_rate`.

    ```javascript
    await fetch("https://xera.app/api/app/content-metrics/update", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Authorization": "Bearer <session_token>",
      },
      body: JSON.stringify({
        content_id: "VIDEO_UUID",
        content_type: "video",
        completion_rate: 0.5,
        engagement_duration: 90,
      }),
    });
    ```
  </Tab>
</Tabs>

## How the Engagement Score is Calculated

The server computes `engagement_score` from your reported values using this formula:

```
engagement_score = (completion_rate × 0.6) + (min(engagement_duration / 300, 1) × 40)
```

A 5-minute (300-second) session with full completion yields the maximum score. Shorter or partial sessions produce proportionally lower scores.

<Note>
  High completion rates directly boost a content item's **freshness** and **creator quality** signals in the recommendation engine. Content that users consistently finish rises in the discovery feed — rewarding creators who produce engaging ARCs, Traces, and videos.
</Note>

## Error Responses

| Status | Error message | Cause |
|--------|--------------|-------|
| `400`  | `"content_id et content_type requis"` | `content_id` or `content_type` was omitted from the request body. |
| `401`  | `"Non authentifié"` | The `Authorization` header is missing, expired, or invalid. |
